# 🍳 DailyFood - Recipe & Suggestion App

React Native öğrenme sürecimde geliştirdiğim; kullanıcı girişi, liste yönetimi ve API entegrasyonu içeren pratik uygulaması.

## 💡 Temel Özellikler

* **🔐 Simüle Edilmiş Yetkilendirme (Simulated Auth):** Kullanıcı adı ve şifre kontrolü ile güvenli giriş simülasyonu.
* **🌐 API Entegrasyonu:** `Öneriler` sayfasında harici bir yemek API'sinden veri çekilerek (Fetch API) listeleme yapılması.
* **❌ Liste Yönetimi:** `Tariflerim` ekranında manuel veri girişi ve listeden eleman silme (State Manipulation) işlemleri.
* **navigation:** Stack ve Tab navigasyon yapıları ile sayfalar arası geçiş.
